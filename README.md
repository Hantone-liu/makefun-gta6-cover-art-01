Cover Studio turns your photos and a caption into GTA 6 poster-style cover art, in your browser.

- **3 multi-panel layouts** — Hero split, Comic strip, Mosaic — that adapt to every export size
- **3 colour grades** — Sunset, Neon night, Pastel day — with sunset and neon tints and a vignette
- **Caption editing** — big gradient lettering with outline and shadow, sub-caption, size and top/bottom position
- **Per-panel photo editing** — crop, pan and zoom each panel; drag to pan, scroll to zoom
- **PNG export** — 1080×1080, 1080×1350 and 1920×1080, one click

Fully offline: the app is static files under `app/`, loads nothing over the network, and your photos never leave your machine.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — or serve `app/` with any static file server.
